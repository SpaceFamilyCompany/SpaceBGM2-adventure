# SpaceBGM aka BGMコンシェルジュ

24時間かけっぱなしにできる、冒険が鳴らす音楽アプリ。

画面の中の動きひとつひとつが音になります。ゆっぴの足音がメロディに、猫のトムの足音がリズムに、スライムの跳ねる音がベースになります。カエル・フクロウ・蛍・花・小川・門まで、森の世界のすべてが同じ拍で動いて、合奏になります。BGMは別に流れる曲ではなく、冒険そのものの音です。

公開先：https://spefami.com/bgm/

## 遊び方

1. **再生**を押すと、いまの冒険が曲として鳴り始めます。画面を閉じても、ロック画面でも鳴り続けます。
2. ゆっぴとトムは自動で森を進みます。1階は16拍（約11秒）、10階で1周（約1分50秒）。曲の再生位置が、そのまま冒険の進み具合です。
3. 階ごとに場面が変わり、曲も変わります。

   | 階 | 場面 | 景色 |
   |---|---|---|
   | 1・3・5・7・9 | 道を進む（背景がスクロールし、門をくぐって次の階へ） | 1〜3 森の入口／4〜7 森の奥／8〜9 霧の森 |
   | 2・6 | スライムと戦う | |
   | 4・8 | 宝箱を開ける | |
   | 10 | 森の守り人（ボス） | 守り人の広場 |

4. 宝箱やボスから装備が手に入ると、ゆっぴが自動で身につけます。見た目と一緒に音も変わります（若葉の剣：はじく音、苔織りのマント：柔らかい響き）。装備がないとボスには勝てず、1階からやり直します。
5. **休む**を押すと焚き火で休憩し、曲も焚き火の曲に変わります。休んでいる間は冒険が進みません。
6. 進行は自動で保存され、留守の間も最大8時間分の冒険が進みます。

## 音の仕組み

- 1コマ = 8分音符。キャラや背景の物が「音の鳴るコマ」に入った瞬間だけ音が鳴り、鳴らない物は動きません。絵と音は同じ楽譜（`web/score.mjs`）から作るので、ずれません。
- 単調にならないよう、階ごとにスウィングの量を変え、区間の終わりにフィルを入れます。ラン（小走りの連打）、ため（わざと止めて遅らせ、2歩で取り戻す）、ブレイク（立ち止まって森の音だけを聞く）があります。
- 手前の花やキノコは、ゆっぴが触れた時に鳴ります。奥の物は数小節に1回、小さな音で鳴ります。
- 曲は端末の中で楽譜から合成したWAVで、1つのHTML Audioでループ再生します（iPhoneのバックグラウンド再生のため）。音声ファイルは配信しません。

## 開発

Node.js 22 以降。外部 npm 依存はありません。

```sh
node build.mjs                  # web/ と scripts/ から worker/index.js を生成
node --test tests/*.test.mjs    # 検証
node scripts/preview.mjs 4320   # http://127.0.0.1:4320/ （メモリー内のサンプル保存）
node scripts/sprite-preview.mjs # dist/sprite-preview.html でドット絵を確認
npx wrangler deploy             # spefami.com/bgm/ へ公開（Cloudflare Workers）
```

| ファイル | 役割 |
|---|---|
| `web/score.mjs` | 楽譜エンジン。各コマの動き・音符・スクロール・背景オブジェクトの配置と、WAV合成 |
| `web/page.html` / `web/app.css` / `web/app.js` | 画面（舞台・階のレール・操作）と再生。合成は Web Worker で行う |
| `scripts/pixel-art.mjs` | ゆっぴ・トム・敵・森の生き物・装備の着せ替えパーツのドット絵（Codex 制作） |
| `scripts/forest-objects.mjs` / `scripts/forest-scene.mjs` | 背景オブジェクト（3段の視差）と景色ごとの空・地面（Codex 制作） |
| `server/game.mjs` | 冒険の進行・装備・報酬 |
| `server/worker.mjs` / `server/store.mjs` | 画面と保存API。保存は Durable Object 1つ |

色は Space Family のブランドカラー（ink・lilac・pink・cyan）です。
