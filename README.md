# SpaceBGM2｜音の冒険

音楽とともにダンジョンを旅する放置RPGの試作版。SpaceBGMから発想を引き継いだ新しい実装です。

## 遊び方

ルウは8秒ごとに階を探索し、ゴールドを獲得します。10階のボスに挑み、踏破すると次の場所の解放条件を満たします。ゴールドでルウを育て、トムを仲間にできます。森・洞窟・古城の3地域があります。

音楽の再生はユーザー操作で始まります。ひとつの拍クロックで探索・戦闘・宝箱・ボスの音を重ね、地域変更のテンポと調は次の小節から切り替えます。すべて端末内で合成します。

## 保存

この試作は所有者だけが利用する非公開アプリです。進行はR2に保存され、留守中の冒険はサーバー時刻から最大8時間分まで計算します。複数タブによる同時更新はETagで制御します。一般公開する場合は、ユーザー認証とプレイヤー別の保存先への変更が必要です。

## 開発

`npm test`でゲーム進行・ボス・解放条件・オフライン上限・保存APIを検証します。`npm run build`でWorkerを生成します。依存パッケージはありません。

`web/index.html`が画面と音楽、`server/game.mjs`がゲーム進行、`server/worker.mjs`が保存APIです。build.mjsが1本のWorkerにまとめます。

## 現在の範囲

1人の冒険者と1匹の仲間。ランダム装備、職業、複数キャラクター編成は未実装。3地域の背景は同じ森のアートを色調変更して使っています。ブラウザがバックグラウンド音声を停止しても進行は保存されます。
